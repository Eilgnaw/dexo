Unified Cloudflare Verification

- A Cloudflare Challenge while browsing or posting on linux.do, or while adding the forum, should show one draggable edge-snapping shield without an alert.
- The shield should offer verification, ignoring the prompt, or disabling read-time reporting when applicable. Cancellation or relaunch should preserve the state; completing verification resumes background requests, while the failed action still requires a manual retry.
- With DoH enabled, the verification page must use the selected DoH configuration and never silently fall back if its proxy fails. DoH-off and iOS 15/16 compatibility should remain unchanged.

Category Filter Button

- On a forum's topic list, confirm the top-left category filter is icon-only and has no selected appearance while "All Categories" is active.
- Select a category and confirm the same icon shows the system selected appearance. Reopen the menu, choose "All Categories," and confirm the selected appearance is removed.

First Launch and Default Forum

- On a fresh installation, confirm https://discuss.python.org is added and opened automatically. Browse public topics, categories, and search without signing in. Auto-open Last Forum should be enabled by default, with no extra prompt to enable it.
- Upgrade directly from an older build. Existing forums, sign-in sessions, and the auto-open preference should be preserved. Existing users with an empty forum list should not receive a default forum automatically.
- Delete the default forum and relaunch. It should not be added again. On an offline first launch, the default forum should still be created, and you should be able to return to the forum list after a loading error.

Direct Cold Launch

- Enable Auto-open Last Forum, enter a forum, fully terminate the app, and launch it again. The forum should appear directly without flashing the forum list or sliding in from the bottom.
- Disable the setting and relaunch. The app should stay on the forum list. Deleting the last-opened forum should also make the next launch return to the list.

Returning and Switching Forums

- Tap the circular button in the top-right of a forum. Confirm the forum list and floating shortcut appear. Tap the shortcut or the same forum in the list to resume at the previous reading position.
- Switch between multiple forums. Manual opens should retain their normal animation without moving the window offscreen, hiding it, or leaving a blank page.
- After returning to the list, confirm you can add or delete forums and open Settings without being sent back into a forum automatically.
- Check navigation bars, safe areas, light/dark appearance, and font-size changes on both iPhone and iPad.

Opening Notifications

- With the app fully terminated, tap a system notification. It should open the notification's forum and topic, take priority over the last-opened forum, and avoid opening the same page twice.
- If the notification's forum has been deleted, the app should show an explanation and leave the forum list usable.
